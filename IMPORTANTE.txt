PARA PODER HACER QUE FUNCIONE EL PROGRAMA TIENEN QUE HACER LOS SIGUIENTES PASOS
-COMO GITHUB NO ME DEJA SUBIR LOS MODULOS DEL PROGRAMA ELECTRON TIENEN QUE INSTALARLO USTEDES
. Requisitos previos
Tienen que tener instalado en su computadora:

Node.js (incluye npm automáticamente).

Git.

2. Pasos que deben ejecutar en su terminal
Clonar el repositorio:

Bash
git clone https://github.com/serpi123/Focus.git
Entrar a la carpeta del proyecto:

Bash
cd Focus
Instalar las dependencias:

Bash
npm install
(Este es el paso clave: npm install lee tu archivo package.json y descarga automáticamente Electron junto con todas las dependencias necesarias directamente en su propia carpeta node_modules local).

Ejecutar la aplicación:

Bash
npm start
